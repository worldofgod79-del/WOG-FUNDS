# WOG-FUNDS

Mobile-first WOG funding tracker.

## Current version
- Dashboard
- Donations
- Expenses
- Permanent browser history using localStorage
- Search and type filter
- Delete transactions
- Running balance
- Mobile responsive UI
- Dark mode

## Important
This version stores data in the browser/device. It is **not yet a shared online database**.

For the next production version, connect the app to Supabase (PostgreSQL + authentication) so multiple authorized WOG admins can access the same permanent online records.

## GitHub

## GitHub Pages
The current frontend can be hosted on GitHub Pages because it is a static HTML/CSS/JS app. For shared permanent online records, use a database-backed version.
